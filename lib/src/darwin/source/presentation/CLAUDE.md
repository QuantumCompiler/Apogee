# The Presentation layer

**Position.** Fourth of the four ([ADR 0001](../../../../documentation/gui/adrs/layer-enforcement.md)): the windows, views and rendering, in SwiftUI -- whose types stay here and nowhere below.

**Modules:** `styles` (the shared visual vocabulary, and the theme switch: the design's three themes or the system's, and the text size), `shell` (the window around every screen: the sidebar and its places, the route, the keys, the overlays and the toast, and the window law; and the parity table, every CLI command's place in the app, ADR 0003), `session` (one chat session: the window, its transcript and cards, over a SwiftUI-free view-model folding the session's events, paused and resumed by the library), `sessions` (the Sessions place: the saved conversations' list and its changes, the one live session, the inspector), `models` (the Models place: the library of every configured and stored model under the CLI's groups, a model's details from its models info document -- the typed facts where the CLI states them -- delete, rename and repair asked and read back, and the roles moved through their verbs), `tasks` (the Tasks place: the ledger's tasks read on focus, a run started from the new-task sheet and followed live from its events, halt, cancel and resume as their verbs), `monitor` (the system monitor overlay: the system read every two seconds while open, and the app's own children's memory), `suites` (the Suites place: each suite's members read through config get, and an honest fit worked out from models info and the system read), `graph` (the Code graph place: a graph's query drawn by a seeded, deterministic layout computed in its view-model, a node explained, its neighbours walked, a rebuild supervised), `video` (the Video place's clips: the records in ~/Movies/Apogee and added folders, a clip's page, the generate sheet's command as typed, the run supervised, the install asked first), `compose` (compositions: a brief composed with its scenes read from the project document as the composer saves it, stopped and resumed by the same command, edited by instruction with its diff), `voice` (the Voice place: the speeches in ~/Music/Apogee and added folders, say with the voice model's own voices, playback lit by the record's sentence timings), `settings` (the Settings window: General, Appearance, Backends & keys, Video & voice, Permissions -- each over its verbs with read-back, a key sent on stdin and kept nowhere), `console` (the console: any apogee command run as typed on the jobs core, completion asked of the binary, the parity table's carve-outs refused with their reasons), `knowledge` (the Knowledge place: the decision records -- list by branch, ask with scores, capture supervised, link, move, delete, export -- and the collections -- health, sources, search as the CLI prints it, ingest supervised, deletes confirmed), `training` (the Training place: runs launched, gated, promoted and rolled back, the regimes, the datasets and their kits -- every long act supervised, nothing started but by the person), `library` (the Library place: agents, symphonies and MCP servers over their verbs -- a play supervised, the person's own definition files edited in place and checked by the binary where it can), `app` (the application: its scenes and the composition of its view-models, each place's screen mounted in the shell).

**Shape** ([ADR 0002](../../../../documentation/gui/adrs/presentation-mvvm.md)): every module but `styles` is `Views/` + `ViewModels/`, with any further directory it genuinely needs; a view binds to its view-model, the view-model consumes Business, and no file under `ViewModels/` imports a UI framework. `styles` -- colors, type, spacing and the common components -- leans on no sibling, and every other module may use it; a component a second module wants is promoted there, never copied.

**The entry point** is not a module: the application target `Apogee` builds `source/main/`, one file that starts `PresentationApp`'s `ApogeeApp` -- the composition root, as the CLI's `source/main.cpp` is -- and embeds exactly the frameworks its links reach at run time, so a module a Presentation module starts linking is embedded the same day.

**May import:** every layer below, the UI frameworks, and `styles` from any module.

**Enforced by:** [`tests/architecture/layering`](../../tests/architecture/layering/LayeringCheck.swift): the edges, the MVVM shape, the view-models' imports and `styles`' independence.

**Changing this layer:** a new module is a directory `source/presentation/<package>/` with `Views/` and `ViewModels/`, a framework target named `Presentation<Package>` in `Apogee.xcodeproj` building that folder, its test bundle at `tests/presentation/<package>/` in the shared scheme, and its name on this card's **Modules** line.
