# CLAUDE.md — the design

Context for agents working on **the design prototype**: the reference every Apogee GUI app is built from. It lives at `lib/design/`, and its queue is [`backlog/design/`](../../backlog/design/README.md). The apps themselves have their own homes ([the router](../../CLAUDE.md)). This is the design's one guide (since item 1t, 2026-11-21); [DEVELOPER.md](DEVELOPER.md) has the app file by file.

## What the design is

A React and TypeScript app at `lib/design/prototype/`, built into one self-contained `lib/design/main.html` that opens with a double-click. Its law is [the design's ADR 0001](../../adrs/design/react-design-prototype.md):
- four layers, mirroring the Mac app module for module, its 20 Presentation modules each a place, `styles`, `shell`, `app` or `gallery`;
- its view-models plain TypeScript that never imports React;
- its data the CLI's own recorded documents, read in place from the Mac app's `Fixtures/` folders or kept in the design's own `fixtures/` (hand-made files named `*-handmade*`), answered by the CLI stand-in on the old prototype's 400 ms clock;
- its tokens one file, `lib/design/tokens.json`, beside the built file: the one place a color, type size, font, radius, layout size, motion or fixed value is written, and the one file other apps copy from;
- its review surface the gallery inside the built file, which took over the claude.ai canvas's job.

It is a reference for building the apps under `lib/src/darwin/`, `linux/` and `windows/`, not an input to any build, and CI never reads it. The logo beside it is the one exception: `lib/design/assets/Logo.png` is the master the macOS app's icon is made from, and that app's suite reads it.

**New design is drawn here:** a new screen or state is a module, a preset and its recordings in this app, never a picture made somewhere else first. An item in another queue that draws design (the Apple apps' 10a, 10c, 8b, 9a, 9b and 7a) draws it here, and is checked by the local gate.

## Opening it

- **Double-click `lib/design/main.html`.** It opens from disk with no server, at `chat`, the default start.
- **A start preset** comes from the address: `main.html?start=models:store`, `?start=settings:appearance&still=true` (`still` stops the clock), `&apogee=missing` or `&apogee=config-typo` for the CLI's two failed modes. The list is `source/presentation/app/Previews/Presets.ts`.
- **The gallery** is the review surface: `main.html?gallery` (the Build page), `?gallery=foundations`, `&board=<id>` for one board at full size (`&board=ScreenModels`, `&board=BuildContract`), `&theme=<dark|light|contrast>`. ⌥⌘G turns the window from the app to the gallery and back.
- **While working**, `npm run dev` in `lib/design/prototype/` serves it with fast refresh at <http://localhost:5173/main.html>.

## The design's rules

These carry over word for word from the old prototype's guide (ADR 0001 §7):

- **Every part maps to the CLI.** The app drives `apogee` over the machine-mode pipes and through the same commands a person types ([machine-mode.md](../../reference/cli/machine-mode.md)). Before drawing something, find the event or command it comes from in that document or the binary's `--help`. If none exists, draw it with its fallback and add the gap to the contract board; never design as if it existed.
- **Honest by default.** Say what the CLI says, in its words where it has them. Never invent a time estimate, a size or a count the CLI doesn't report; mark anything billed or sent off the machine.
- **Every color is a token.** Use `var(--surface-window)` and its 24 siblings, never a hex. The only fixed values are the modal scrim, the shadows and the window controls. Type sizes are `var(--t-…)` and fonts `var(--font-ui)` and `var(--font-mono)`, so Settings › Appearance changes everything.
- **Keyboard first, accessible as drawn.** Real `<button>`, `<input>` and `<label>` elements, an `aria-label` on icon-only buttons, a key for every destination, and text at 4.5:1 against what it sits on.
- **Copy is plain words:** short sentences, no jargon a person wouldn't use, no emoji.

Where a rule names a part of the old prototype, its counterpart here takes its place, and the rule itself does not change: the contract board is the gallery's contract page (`gallery/Models/contract.ts`), and the token names are tokens.json's, drawn as those CSS variables. The token scan (`npm run layering`) holds the third rule; review holds the others.

## What a change touches

| Changing | Update |
|---|---|
| A screen, a flow, copy, behavior | Its module's view-model and view (`source/presentation/<module>/ViewModels/`, `Views/`), with the view-model's test first; the gallery's frames follow on their own. |
| A new screen or state worth its own board | A start preset (`app/Previews/Presets.ts`, with what it opens in `AppViewModel.applyStart`); its fixture (a recording the Mac app holds, a capture by `npm run capture`, or a hand-made file in the CLI's shape under `fixtures/`, named `*-handmade*`); its test; and its gallery entry at the end of its row in `gallery/Models/Boards.ts` (`noOldBoard: true`), which the test "every preset has a frame" asks for. |
| What a part of the design needs from the CLI | `gallery/Models/contract.ts`: a row in `contractRows`, and a gap in `contractGaps` at the next free id (G33 today) if the CLI doesn't offer it. The stat cards count themselves. |
| A color | `colors` in `lib/design/tokens.json`, in all three themes. The color page computes every contrast from it. |
| A size, a region, a key | tokens.json's values (`layoutPx`, `controlHeightPx`, `radiusPx`, `spacingPx`, `motion`), and for a key the shell's key map (`shell/ViewModels/KeyMap.ts`), which Settings › Keyboard and the layout page read; a key the layout page's `keyRows` does not name fails its test until it does. |
| The logo | Replace `lib/design/assets/Logo.png`, re-measure the rocket's crop in `lib/src/darwin/scripts/icon.sh` if the rocket moved or changed size, and run `icon.sh generate`, which rewrites the app's icon and `Logo-320.png`, the copy the gallery's Logo page draws; then rebuild. |
| A component's look | The component (`styles/Components/` when shared, else its module's), its previews, and its specimen (`<module>/Previews/Specimens.tsx`) when a Components page shows it. |

Every change ends with `npm run build`, which writes `lib/design/main.html`, committed with its sources. [DEVELOPER.md](DEVELOPER.md) has the recipes ([porting a place](DEVELOPER.md#styles-the-shell-and-the-first-screen), [the gallery](DEVELOPER.md#the-gallery), [the Build pages](DEVELOPER.md#the-build-pages)).

## Checking a change

The check is the local gate: `npm run check` in `lib/design/prototype/`, which runs the typecheck, the unit tests, the layering check, the staleness check and the Playwright tests that open the built file from disk, and never rebuilds ([DEVELOPER.md](DEVELOPER.md#develop-build-and-check)). Run it before every commit. A change to anything the build reads leaves `main.html` stale, and the check says so. `npm run parity` and `npm run baseline` stay outside it: they compare the app against the old prototype's pictures, which 1c's baseline re-makes from git history.

## Working process

The docs-first lifecycle and its conventions are the CLI's ([`assistant/cli/CLAUDE.md`](../cli/CLAUDE.md)); this home states only its deltas. A change is specced in [the backlog](../../backlog/design/README.md) as a ticket (key `DSN`, its [Document format](../../backlog/design/README.md#document-format)), built from its document, and recorded in [MILESTONES.md](MILESTONES.md). Each step that changes the queue's index changes the [backlog overview](../../backlog/README.md#keeping-this-page-true) in the same pass. The plan is [ROADMAP.md](ROADMAP.md).

The design is not an input to any app's build, and CI never reads it, the logo aside (above). Its checks run locally before a commit: `npm run check` in `lib/design/prototype/` ([DEVELOPER.md](DEVELOPER.md#develop-build-and-check)). `changed.sh` and the workflows name nothing of it but the logo, `lib/design/assets/Logo.png`, which `changed.sh gui-darwin` lists because the macOS app's suite holds its icon set to it.
