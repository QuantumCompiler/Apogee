# The delegate: a bounded sub-session as a tool

**What / why.** The way a long coding job stays inside a context window is delegation: hand a self-contained piece to a fresh context, get back the conclusion, keep working — Claude Code's Task tool. Apogee has no tool-using sub-agent (the execute-mode spike's W5, 2026-10-11, measured): `consult` is **brief-only by recorded design** (one bounded, brief-only, serial, narrated member call — `agentloop/member_call`, the deliberate single path), symphony stages are tool-free (27q — ungated *because* a stage calls no tools), and no delegate machinery exists in `business/` (grep). This item builds **the delegate**: a native tool (`delegate`) whose call runs a bounded sub-session — the same agent loop, a fresh context, the tools the parent offers, **the parent's own permission gate** — and returns the sub-session's final answer as the tool's result, the whole run narrated in the parent as a labeled side call with its own tool lines. One level deep, budgeted, cancellable with the parent's turn. It is the wave's biggest item and the one that makes "compares to Claude Code" true rather than polite.

**Core constraint(s).** **The one loop, re-entered — never a second implementation**: the delegate composes the existing `agentloop` run for its sub-session (the ADR 0002 smell is a copied loop; the layering already lets `tools/` reach `agentloop/`). **One permission gate**: the sub-session shares the parent's checker — the config's permissions, the session's answers, the 27i ceiling; a prompt a sub-tool raises reaches the person through the parent's prompt surface (terminal, shell widget, machine-mode event) exactly as the parent's own would, and an `always` writes once through the one editor. With nobody to ask (a pipe, an unattended task), a sub-ask denies as it does today. **Bounded by construction**: a per-delegate turn cap and token budget (named constants, the tool refusing past them in its result), depth exactly one — a delegate's kit excludes `delegate` — and the parent's cancellation token cancels the sub-session mid-turn (28f semantics). **Narrated honestly**: the parent's front ends show the delegate as a side call carrying its tool lines (26n's `on_side_call` plus the notice-sink idiom 27t built for orchestrated plays); machine mode says it in the pinned vocabulary, documented in the same change. The sub-session is **not saved** as a user session — its transcript lives inside the parent's record as the tool call's detail, never a second chat in `chats list`.

**Seam + files.**
- `lib/src/cli/source/business/tools/delegate.h/.cpp` — the tool: arguments (the brief, optionally a role for the sub-session's model), the sub-session composition over the loop, the caps, the result (final answer + a one-line account of tools used).
- `agentloop/` — what re-entry needs exposed (a loop run over a fresh message list sharing the Harness, reporter hooks for the nested narration) — composition, not a new loop.
- `cli/` — the kit wiring (registered with `--tools` in chat and execute; the registry's environment note names when to delegate), the permission plumbing already shared.
- `machine/protocol` + `machine-mode.md` — the delegation narration's events (the side-call vocabulary extended if a field is missing).
- Tests: `tests/business/tools/delegate_test.cpp` (caps, depth-one, result shape, cancellation), loop-level nesting over mocks (a delegate's gated tool prompting the parent's surface; an `always` written once; denial on a pipe), machine-mode conformance, the TUI session case (the side call folding as consults do), the leak test's surfaces.

**Reference.** 27f (`member_call` — the brief-only path this deliberately does **not** widen: consult stays consult; the delegate is a different tool over the loop itself); 27t (the notice sink and labeled side-call narration for a nested run — the rendering precedent); 26g (the core set: `delegate` joins `consult` in it, never dropped by selection); 27i (the ceiling the shared gate keeps); the execute-mode spike (2026-10-11) for W5.

**Decisions made** (dated):
- 2026-10-11 — The set lands in v0.1.7 as track 41, the delegate **in the wave, last** (the spike's recommendation, standing — the user executed without a trim).
- 2026-10-11 — Depth is exactly one: a delegate cannot delegate (the cap that keeps the budget arithmetic and the narration readable; a real need for two becomes its own item's evidence).
- 2026-10-11 — The sub-session runs on the session's own model unless the call names a **role** (resolved through the one resolver) — never a backend by name from the model's mouth.
- 2026-10-11 — The sub-session's transcript is the tool call's detail inside the parent's record, never a saved chat.
- 2026-10-11 — **The parent's checker now carries the session's permission mode** (39b shipped the same day, recorded here by the pre-MR docs pass): `make_permission_checker` reads `SessionApprovals::mode` at each call, so a delegate sharing it inherits the mode as it stands when each sub-call reaches the gate -- plan mode refuses the sub-session's writers too, dont-ask its asks, bypass asks nothing, and a deny wins in every mode. A mode's refusal reason reaches the sub-session's tool results through `DispatchContext::refusal` (`mode_refusal`), and plan mode's turn note (`plan_note`) is the parent's to hand the sub-session's system prompt, or the sub-session plans blind. `ToolGate::approvals` is the handle on the mode.

**Open calls:**
- [default: caps — 8 sub-turns and a token budget named beside it; the tool result reports spend either way.]
- [default: the delegate's kit is the parent's kit minus `delegate` (and minus nothing else); a narrower kit per call is a later item if wanted.]

**Guardrail(s).** Depth-one and the caps enforced (a delegate offered `delegate` is a planted failure); the shared gate proven (a sub-tool's `always` leaving exactly the one config edit; a pipe's denial identical with and without nesting); cancellation mid-sub-turn releasing both loops; machine-mode conformance with the narration; parent-record round-trip (resume shows the delegation's account); the leak test across the nested surfaces; optional real-weights pass per the model families (one family, one delegated fixture job, recorded).

**Acceptance criteria:**
- [ ] A tools-on session can delegate: the sub-session runs the same loop with a fresh context under the parent's gate and budget, and its answer returns as the tool result.
- [ ] Depth one, caps, and cancellation hold; prompts from sub-tools reach the person through the parent's surfaces; denials on a pipe unchanged.
- [ ] The delegation narrates as a side call with tool lines in all four front ends; the machine event is documented and pinned.
- [ ] No second loop, no saved sub-chat, no gate widening; the full suite green.

**Scope note.** Earmarked for v0.1.7; gated on [41a](execute-opens-bare.md) (the mode it exists to serve opens first) — buildable beside 41b–41d in any order after it. Out of scope: depth beyond one, parallel delegates, per-call kit narrowing, consult/symphony changes.
