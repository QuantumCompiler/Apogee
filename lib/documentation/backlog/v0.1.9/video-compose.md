# The composer: a brief into a narrated video

**What / why.** The strongest pattern in the current crop of video tools, verified against the market leader's reviewed feature set (the composer spike, 2026-10-19): one prompt becomes a finished video — a script written and split into scenes, media per scene, an AI voiceover, timed captions, music, and the whole thing assembled — with the honest caveat the reviews agree on (weak at exact shot control: it is a composer, not a frame editor). Apogee now holds every piece but the glue: clip generation with reproducible records (49, shipped), the voice with measured durations (50a ([shipped, Milestone AN](../../assistant/MILESTONES.md#milestone-an--the-composer))), the assembly operations (50b ([shipped, Milestone AN](../../assistant/MILESTONES.md#milestone-an--the-composer))), structured scene planning (26f's machinery), the resumable-manifest idiom (the training pipeline's). This item is the glue: **`apogee video compose "<brief>" [--music <bed.wav>] [--assets <dir>] [--no-captions] -o out.mp4`** — one schema-held member call plans the scenes (narration line, visual prompt, duration target, each within the caps); each scene then renders as **one recorded clip run** through 49c's core (or takes a user asset from `--assets` when the plan names one) and **one narration segment** through the voice core; captions are **arithmetic, not transcription** — we own the script and the voice's measured durations, so `write_srt` times them with no ASR; assembly concatenates, mixes the narration over the optional bed, and burns the captions. The whole run is a **project document** — the scene list with every clip and audio record, the 49 sidecar law scaled up — written beside the output, **resumable per scene**: a crash re-renders only the scenes whose records are missing, and spend honesty comes first (the plan is printed with its scene count and the expected scale — N scenes × minutes each on this device — before any generation starts).

**Core constraint(s).** **No new model paths**: the plan is one structured member call (26f, validated with the one corrective retry); clips run through 49c's core over closures (the composer never names a backend); narration through the voice core; nothing else calls a model. **The project document is the only state** — scenes, prompts, seeds, record paths, durations, the parent brief — written through the sidecar discipline, chaining per 49d's law; resumption reads it and fills gaps, never regenerates what stands (the pipeline-manifest idiom). **Captions are owned text**: the script's own lines timed by measured durations — never ASR, never a guess; `--no-captions` opts out, default on. The caps (scene count, per-scene duration) are named constants quoted in refusals; the brief's plan is shown and the expected spend said **before** generation. Stock-footage services, avatars, voice cloning and music generation are the **recorded outs** — `--assets <dir>` (the user's own stills and clips, offered to the plan by filename) and `--music <bed.wav>` are the MVP's honest substitutes. Cancellation cleans the in-flight scene only; finished records stay. Every mode: the document per 28h, the verb classified (exec line), progress through the seam.

**Seam + files.**
- `business/video/compose.h/.cpp` (the module the runtime items established, grown) — the project document (schema, read/write, resume logic), the scene walk over closures (plan, clip-per-scene, narration-per-scene, assemble), the caption timing.
- `presentation/cli/video_cmd.cpp` — the `compose` verb, flags, the plan-and-spend print, the gate-free local run (it writes only its outputs), progress, the parity row; machine-mode.md's document row.
- `data/contracts/` — the project document's schema beside the run document's (one family, versioned).
- Tests (fake drivers throughout): the plan held to its schema over a scripted model; the walk's matrix (every scene rendered once; a user asset slotted; resume filling only gaps; cancellation keeping finished records); caption cues against measured fixture durations; assembly handed exactly the records' paths (argv pinned through the fakes); the document conformant and chaining; the spend print golden.
