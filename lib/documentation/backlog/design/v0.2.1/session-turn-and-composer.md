# The session's turn and the composer, with the plain states

**What / why.** The first half of the session screen in the React prototype (design 1f, split on 2026-11-19; [1v](session-scenarios-and-states.md) is the second half). It builds the `session` module that every chat preset draws on: one turn grown only from the CLI's recorded machine-mode streams, replayed through 1d's stand-in, never a counter over a string. It also builds the composer, the header, the answer's markdown and code, and the four presets that need no scenario. So this part replaces the canned reply and the fixed play markup with replayed streams, and lays down the module and the recordings recipe that 1v's scenarios build on.

**Core constraint(s).**
- **The prototype is the source of truth for behavior.** The port keeps every state, control and word the old screen draws. It takes the Mac module's shape and names, and names each place where the Mac app differs.
- **Every line of the transcript comes from a replayed stream.** A line comes from a recorded event, a recorded `chats show` document, or the text the preset itself sent, never from a counter over a string. A stream is the binary's own recording or a hand-made file in the CLI's exact shape named `*-handmade*` ([ADR 0004](../../../adrs/darwin/module-schemes-and-previews.md):46, "never shapes made up").
- **The four layers and MVVM** ([layer enforcement](../../../adrs/gui/layer-enforcement.md), [presentation MVVM](../../../adrs/darwin/presentation-mvvm.md), [the design's ADR 0001](../../../adrs/design/react-design-prototype.md)). View-models are plain TypeScript classes that never import React. They get the chat starter, the reads and the clock by injection from the stand-in (1d), and never the stand-in itself.
- **The design's rules** ([`lib/design/spec/CLAUDE.md`](../../../../design/spec/CLAUDE.md#the-designs-rules)): every color a token (the code colors are tokens.json's five `code.*` tokens), keyboard first, the CLI's words, and billed use marked.
- **Recording never touches a real home.** A capture runs the branch build, `lib/src/cli/build/macos-arm64/source/apogee`, in a throwaway `APOGEE_HOME` and working folder, on the mock backend: no model and no network. It never runs `~/.local/bin/apogee` (which is `capture-fixture.sh`'s default), and it never touches `~/.apogee` or `~/.apogee-dev`.
- **The old prototype stays frozen**, and the Mac app's files are not changed. Any edit under `lib/src/darwin/` triggers the `gui-darwin` pipeline (`lib/scripts/changed.sh:50–65`).

**Guardrail(s).**
- **A test per preset**, the successor of the 30-tick check. The four presets join 1e's `Presets.test.ts`, whose walk gains the session's view state (transcript, composer and header). Each is checked at the three `apogee` modes, still and after 30 ticks, and fails on a throw, an unanswered call, or `undefined`, `null` or `NaN`, naming the preset. Each preset's rules answer its chat and its `models list` and `models info` reads. It is proven on a planted preset whose chat rule is missing, which fails naming the unanswered launch. `monitor` stays green with no chat rule, since it opens no session.
- **Event coverage.** Every `type` in the streams this part replays maps to a transcript item or a named skip, as the Mac app skips `tool_call`. A planted unknown type is kept as an unknown line, never guessed (as `SessionGrowthTests.swift:20` holds for a `sources` event with no list).
- **No counter remains.** A test fails if a view-model's transcript text is not traceable to a replayed event, a recorded document or the preset's own sent text. It is proven on a planted canned reply.
- **Replay end to end.** View-model tests replay `markdown-answer.jsonl`, `code-answer.jsonl` and `stopped-turn.jsonl`: the pending line, the reasoning, the answer as its deltas join, the result's footer, and Stop writing a cancel only while a turn is in flight.
- **The markdown component.** Each block `markdown-answer.jsonl` carries is drawn. Each recorded fence the Mac's `CodeLexer` knows is colored; the unnamed and elixir fences are drawn plain, as `CodeLexerTests.swift:275` holds. The image draws no `<img>` (a render of `markdown-answer.jsonl`'s answer holds none, so it asks nothing of the network), and the `file:` link is drawn but not followed. The token scan holds the five code colors to `var(--code-…)`.
- **The private confirm** is asked only when a private session has a turn sent, with the right body for a turn running or not, and "Keep it running" leaves everything as it was.
