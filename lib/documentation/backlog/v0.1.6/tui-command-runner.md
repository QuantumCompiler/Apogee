# The command runner: every verb and flag, from inside the shell

**What / why.** Track 37's views give the shell curated surfaces; this item gives it the **whole command language**. The second parity spike (2026-10-10, the installed binary against a sandboxed `APOGEE_HOME`) measured why forms can never be the answer: **119 leaf command surfaces carrying 434 flags** (maximum 36 on `execute`; 31 surfaces with ≥5 flags) — the hand-built-views anti-pattern at roughly fifteen times the size that got Ommi's TUI deleted. The structural answer is **one exec line**: an input on the shell (global, and on each view scoped to its tab's command group) that speaks the CLI's own grammar minus the leading `apogee`. A typed `models pull <ref> --quant Q4_K_M` **is** the command — tokenized once, completed by the binary's one completion core, executed as a **captured child of the shell's own binary**, its output streamed to the stage, its exit code shown — so every verb and every flag works in the shell by construction, byte-identical to a script's run, and nothing per-verb ever needs maintaining. The spike proved the pieces live: `__complete` answers every position (the root's 25 subcommands; `models`' verbs; `models pull --` → its five flags; `config set-default ""` → the typed hint `:hint name BACKEND: …`), a child on a pipe prints the scripts' plain bytes with the command's own words, and the binary defends its own doors (`apogee tui` on a pipe refuses with its reason; `auth add` with empty stdin ends "no key entered" — measured, no hangs). Closes the runner spike's walls W1 (scale), W2 (execution/capture), W3 (tokenizing) and W4 (the interactive doors); W5 was this item's `[user]` call, answered the same day it was asked (2026-10-10: the three refused — see Decisions); 37a's record ([Milestone AH](../../assistant/MILESTONES.md#milestone-ah--the-full-screen-tui)) owns W6 (the classification's runner semantics).

**Core constraint(s).** The TUI stays **strictly additive**: the runner spawns the CLI, never a second implementation — parity is the child's bytes, proven golden, not promised. **In-process capture is off the table**: the only capture today is the test fixture's `std::cout.rdbuf` swap (`tests/support/cli_home.cpp:60`), process-global and unsafe beside the pump and a live session thread — the child is the design, not a convenience. The child gets the **mandatory stderr sink** (the child's-stderr invariant: captured, streamed with stdout, never the terminal's), its three pipes and nothing else (`platform/child_process`), the shell's own root and channel passed through (M10's chain: the same `APOGEE_HOME`/flags the shell runs under), and **no PTY**: plain pipe output is the parity anchor, never a color emulation. Completion goes through the **in-process completion core** (ADR 0007's one answerer — the same core `__complete` and the session view already use), fed by the same tokenizer the run path uses — one splitter, never two. The refusal list is **fed by the law's classification table** (37a's record ([Milestone AH](../../assistant/MILESTONES.md#milestone-ah--the-full-screen-tui))), one source: a refused command names its recorded reason. Ctrl-C kills the running child and nothing else; a running child blocks no frame (the pump's law). No listening socket anywhere in this item.

**Seam + files.**
- `lib/src/cli/source/presentation/tui/runner_view.h/.cpp` — the exec line and its output region (the scrolled lines of [37e](tui-progress-seam.md)'s widget reused): the input row, candidates offered on Tab, the streamed output, the exit line (`exit 1` dimmed when non-zero), Ctrl-C wired to the kill.
- `lib/src/cli/source/presentation/cli/tui_runner.h/.cpp` — the composition: the tokenizer feeding both paths, the completion call into the one core (`cli/complete_protocol`'s), the child spawn (`platform::executable_path()`, the shell's root flags/environment carried, argv from the tokens), the refusal check against the law's table, the per-view scoping (a view's group prefixed to the words); wired into the shell and every view by `cli/tui_cmd.cpp`.
- `lib/src/cli/source/presentation/cli/line_tokens.h/.cpp` — the quote-aware line→argv splitter (POSIX-style quoting, no expansion), one function, shared by run and complete.
- `tests/presentation/cli/tui_runner_test.cpp` (new) and `tests/presentation/cli/line_tokens_test.cpp` (the quoting table); a `cli.tui_shell` PTY case addition (a command typed into the exec line on a real terminal, its output on the stage, the modes restored).

**Reference.** [ADR 0007](../../adrs/cli/tab-completion.md) and `completions/apogee.bash` — the words contract this consumes (the stub splits on whitespace before asking, `apogee.bash:17-21`; the runner's tokenizer is that split grown quote-aware); `tests/support/cli_home.cpp:60` — the rdbuf evidence that rules in-process capture out; 37e — the output region reused, never re-owned; the `$EDITOR`/secret walls recorded on [`tui-agents-mcp-views.md`](tui-agents-mcp-views.md); external prior art: the `:` exec line of vi and less — a full command language behind one key, no forms.

**Decisions made** (dated):
- 2026-10-10 — The set lands in v0.1.6 on track 37 (the user's placement call on the spike report; 37h the track's next letter).
- 2026-10-10 — **Captured child over in-process dispatch**: the rdbuf swap is process-global state beside live threads, and the child's bytes are the parity proof scripts already rely on (the spike's measured design, accepted).
- 2026-10-10 — **One tokenizer** feeds completion and execution, so what Tab saw is what runs; the stubs' whitespace-words contract is its floor.
- 2026-10-10 — **Refusals come from the law's table**, never a second list: `chat`, `execute` and `tui` refuse naming the Session view as their door (`tui`'s own refusal measured on a pipe); the `$EDITOR` verbs (`agents edit`, `symphonies edit`) refuse naming the prompt (their wall recorded on 37g).
- 2026-10-10 — **The self-destructive three are refused** (the user's call, 2026-10-10): `reset` and `uninstall` refuse because they delete the data directory the running shell stands on, `serve` because it is a daemon the shell would orphan — each naming its reason, all three one terminal away at a real prompt. Everything else, all 434 flags across 119 surfaces, runs.
- 2026-10-10 — The exec line opens on `:` from any view (the vi idiom), scoped to the view's group where one exists (`:pull …` in Models runs `models pull …`), unscoped on `!`-prefix or from Home — the exact keys the build's call within this shape (the default, confirmed 2026-10-10).
- 2026-10-10 — A child's stdin is closed: `auth add` through the runner ends in the command's own measured "no key entered", and storing a key stays the real prompt's job — the secrets rules on 37g untouched (the default, confirmed 2026-10-10).
- 2026-10-10 — Output is the plain pipe rendering, streamed as it arrives, no `\r`-repaint or color emulation — the stage shows exactly what a script sees, which is what the parity goldens compare (the default, confirmed 2026-10-10).

**Guardrail(s).** The parity golden: a command run from the exec line captured byte-identical to the same command on a pipe outside the shell, over a read, a mutation (the file compared too) and a refusal. The tokenizer's quoting table (spaces, quotes, escapes, empty words). Completion equality: the candidates the exec line offers equal `__complete`'s for the same words, across a verb, a flag and a value position. A refused command surfaces its recorded reason and runs nothing (the planted case: `tui` typed into the line). Ctrl-C kills the child, the exit line says so, the shell lives on; a slow child never delays a frame (manual-pump case). The leak test registers the runner's output region.

**Acceptance criteria:**
- [ ] Every view carries the exec line; typed verbs and flags run as captured children with the shell's own root, streamed to the stage with their exit code.
- [ ] Tab completes verbs, flags and values through the one completion core, equal to `__complete`'s answers.
- [ ] The parity goldens hold: bytes and written files identical to the same commands on a pipe.
- [ ] `chat`/`execute`/`tui`, the `$EDITOR` verbs, and `reset`/`uninstall`/`serve` (the user's call, 2026-10-10) refuse with their recorded reasons, each recorded in the law's table.
- [ ] Ctrl-C kills only the child; a running child never blocks the pump; the full suite is green.
