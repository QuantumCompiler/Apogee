# The Infrastructure layer

**Position.** First of the four ([the design's ADR 0001](../../../../documentation/adrs/design/react-design-prototype.md), applying [GUI ADR 0001](../../../../documentation/adrs/gui/layer-enforcement.md)): the mechanisms everything stands on. In the prototype they are stand-ins: nothing here starts a process, reads a file at run time or reaches the network.

**Modules:** `clock` (the old prototype's 400 ms tick: a preset's start ticks applied at once, still stopping it there, a fixed "now" and the replay's pace; tests drive it by hand), `process` (the stand-in for running apogee: an argument list answered from a preset's rule table with what the CLI printed, in the three modes installed, missing and config-typo). Both are design 1d's.

**What `process` holds:** `StandInChild` and its rule table -- each answer's replay rules too, `exitAfter`, `Freeze`, `Continuations` and `cancelled` (design 1v), a rule's `exact`, answering its arguments whole (1h), `busy`, its stderr played a line a tick as the busy line before its stdout (1j), and `until`, a rule refused until a call it names has succeeded, and `holdAt`, where a job's wait stands among its lines (1k), and `refusedWhile`, a rule refused while a folder file holds a text, and `configFree`, the verbs `config-typo` passes to the rules since the CLI reads no config for them (1n) -- the `Preset` type (so a place's `Previews/` can name one; its `console` rules answer the console's own child beside the preset's, 1g), the Mac app's `ChildExit`, `BoundedTail` and `LineFramer`, `AsyncStream`, Swift's stream, which TypeScript lacks, and `StandInFolders` (1k): the folders the CLI writes into -- `~/Movies/Apogee`'s clips and their `video.generation` records -- answered from a preset's `folders`, since no CLI verb lists the clips it made and the Mac app reads those files; and an answer's `writes` (1l), the files a job writes into those folders as it plays -- the composer's project saved after every step, its `stopped` twin left by a Stop -- with the child resuming the same command from the write a Stop left (`StandInChild.folders`, `stopped`); and `FolderWriting` (1n), a file the app itself writes there -- the Library editor's save of a definition file the CLI reads, as the Mac writes it with Foundation. The stand-in is handed its recordings: nothing in this layer imports one.

**May import:** this layer only, and the packages `package.json` lists as dependencies. No React, no `.tsx` file, no Node built-in (the app runs in a browser), no module above.

**Enforced by:** [`tests/architecture/layering`](../../tests/architecture/layering/LayeringCheck.ts), which reads [`modules.json`](../../modules.json) and fails an upward or undeclared edge, React below Presentation, anything from outside the prototype, and this card when its **Modules** line disagrees with the map.

**Changing this layer:** a new module is a folder `source/infrastructure/<module>/`, its entry in `modules.json` with what it may depend on, its tests at `tests/infrastructure/<module>/`, and its name on this card's **Modules** line, in backticks. Its name and its interfaces' names are the Mac app's ([its card](../../../../src/darwin/source/infrastructure/CLAUDE.md)).
