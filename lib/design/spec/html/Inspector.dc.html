They want partial-failure tolerance. TaskGroup is all-or-nothing by design: the first child that raises cancels the rest. Two options. Catch TimeoutError inside _fetch() so the child never fails, or switch to gather(…, return_exceptions=True). Catching in the child keeps structured cancellation for real errors, and run_batch() is also cancelled on shutdown (line 71), so that path has to keep working. asyncio.timeout() only turns its own deadline into TimeoutError; an outer cancel still arrives as CancelledError, so catching the timeout won’t swallow shutdown.
