A theme file

A user’s changes, and nothing else. The same file works on macOS, Windows and Linux. The app owns it; the command line never reads it.

How a color is chosen

  1. The user’s change to this token in this theme.
  2. The theme’s own value.
  3. For a token the theme doesn’t name (a file written before the token existed), Graphite’s value. Settings lists it as “from Graphite”.

Rules for built-in themes

  • All text tokens meet 4.5:1 on every surface they sit on.
  • Model types differ in hue and lightness, and always come with an icon and a word: color is never the only signal.
  • Amber means spending: money on a cloud API, or room in the context window.
