Making media

The pieces of Video and Voice: the player, a run’s progress, a clip’s record and history, the generate form’s controls, a composition’s timeline and scenes, the edit preview, voices, and the install prompt. Every value here is one a CLI document or command carries.

The frame keeps the clip’s own aspect. The corners say what the file is; the line under the frame says where you are. A composition’s scene boundaries are ticks on the line.

The install prompt

A child process on a pipe never asks, so the app asks: what is missing, the set it belongs to, where it goes and roughly how big. A yes runs apogee train setup --with <set> and the run that needed it carries on.

ASKING

LoRAs need peft

diffusers loads a LoRA through peft, and Apogee’s Python environment doesn’t have it yet. It’s the one package of the video set that’s missing.

Needspeft>=0.13 · small, pure PythonThe setvideo: torch diffusers transformers accelerate ftfy sentencepiece peftInto~/.apogee/training/venv, by its own pip, and nowhere else
